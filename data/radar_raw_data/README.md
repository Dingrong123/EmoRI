# Optional raw radar captures

Put reconstructed ADC files named `0516env_new_E_X_Raw_K.bin` here to run the raw-reader stage. Raw captures are excluded from Git and the prepared source/sample archive. The two preprocessed examples can be run without them.

No public raw-data download location has been configured for this release candidate. File packing, frame counts, synchronization assumptions, and commands are documented in [the data guide](../README.md) and [the main README](../../README.md#optional-raw-radar-recordings).
